# santydev.space

Personal portfolio built with Astro and Tailwind CSS.

Terminal-dark aesthetic for an infrastructure + security builder.

## Stack

- Astro
- Tailwind CSS
- JetBrains Mono + Space Grotesk

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
```

Static output in `dist/`.
